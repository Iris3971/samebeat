# Phase0 — 公开实测摘要

2026-09-26 历史记录：macOS 26.5.2 / QQ Music 11.8.1 / media-control 0.7.7。验证了标题、歌手、专辑、时长、进度、时间戳、播放状态与 QQ bundleIdentifier。

- 暂停事件可能只有 playing=false；需要冻结外推进度。
- 其他媒体源可以遮挡仍在发声的 QQ；采用 occluded，不能解释为停止。
- 切回 QQ 可能先重放旧缓存；依时间戳拒绝旧进度。
- contentItemIdentifier 不稳定；歌曲身份使用标题、歌手、专辑和时长。
- 切歌包含短暂归零与暂停闪烁；使用 debounce。
- 单曲循环没有显式循环事件；结尾附近进度回零作为启发式依据。
- 历史人工对比进度误差小于 1 秒；不是所有设备的精度保证。

测试控制命令仅属于历史技术验证，v0.1 Agent 与 MCP 不提供播放控制。

公开回放样本位于 fixtures/：保留测试所需时间与 QQ 字段，去除其他应用的真实媒体内容和不需要的系统标识。原始日志不随发布。
